# صفحات هبوط مكتب عبدالعزيز العديني

صفحات عربية سريعة ومخصصة لحملات الإعلانات، مبنية كملفات HTML ثابتة داخل المستودع. لا تحتاج إلى npm أو خادم تطبيق؛ يقدّمها Vercel مباشرة.

## عناوين الصفحات

| المجموعة الإعلانية | رابط الإعلان | الملف الثابت |
|---|---|---|
| عامة | `https://adslanding-law.vercel.app/` أو `?service=general` | `index.html` |
| قضايا جنائية | `https://adslanding-law.vercel.app/?service=criminal` | `criminal.html` |
| أحوال شخصية وميراث | `https://adslanding-law.vercel.app/?service=family` | `family.html` |
| توثيق عدلي | `https://adslanding-law.vercel.app/?service=documentation` | `documentation.html` |

تستخدم `vercel.json` قواعد `routes` لمطابقة `service` قبل الوصول إلى ملف `index.html` الموجود في الجذر؛ توجّه القيم الثلاث إلى ملفات HTML المطابقة، وتعيد القيم الأخرى إلى الصفحة العامة. لا تتغير معاملات الحملة الأخرى مثل `gclid` و`utm_*`. خدمة القضايا العمالية متوقفة في هذه النسخة، لذلك لا يوجد لها مسار مخصص.

كل صفحة تحتوي مسبقًا في HTML على عنوانها ووصفها وH1 ومحتواها وبيانات المشاركة؛ لا تعتمد مطابقة الإعلان على JavaScript. الروابط الداخلية المحدودة هي أزرار التواصل/الخريطة وأسئلة شائعة، ولا توجد قائمة خدمات طويلة أو نموذج يطلب بيانات الزائر.

## محتوى وتحويلات الصفحة

- اتصال المكتب: `055 679 9995`، ورابط الاتصال `tel:+966556799995`.
- العنوان: جدة، طريق صاري، حي الروضة، 23326؛ ورابط الخرائط محفوظ في أداة البناء.
- أربع شرائح في كل صفحة تفتح واتساب برسالة أولية تتضمن موضوع الاستفسار.
- نافذة تواصل مختصرة تظهر بعد تحميل الصفحة مرة واحدة في جلسة التصفح. يظل العنوان والنص ملائمين للخدمة؛ `?popup=1` مخصص لمعاينة النافذة في كل تحميل ولا يحفظ علامة الجلسة.
- على الجوال، يظهر شريط اتصال/واتساب ثابت؛ وعند فتح النافذة يختفي الشريط لتجنب التداخل.
- صفحة العمالية لا تُعرض كخدمة مفعلة في هذه النسخة؛ معاملات الإعلانات غير المطابقة تذهب إلى الصفحة العامة.

### SEO والفهرسة

هذه الصفحات مخصصة لحركة الإعلانات وليست صفحات محتوى عضوية: تحتوي كل صفحة على `noindex, nofollow` وcanonical خاص بها. يسمح `robots.txt` بالزحف حتى تستطيع محركات البحث قراءة توجيه noindex. لا يوجد sitemap مقصود لهذه النسخة.

## الأداء والأصول

- HTML وCSS المهم داخل الصفحة؛ JavaScript صغير ومؤخر إلى نهاية المستند، ولا توجد مكتبات واجهة أو خطوط خارجية.
- تُحمّل محليًا أوزان Tajawal ‏400 و700 بصيغة WOFF2 مع `font-display: swap`، وتُستبعد الأوزان غير المستخدمة من صفحات الهبوط.
- الشعار WebP صغير بأبعاد ثابتة؛ صورة المكتب WebP، وتُحمّل كخلفية زخرفية على الشاشات الكبيرة فقط، ولا تُحمّل على الجوال.
- أسماء الأصول تحتوي بصمة محتوى؛ تضبط `vercel.json` تخزينها المؤقت لمدة سنة، بينما تبقى ملفات HTML قابلة للتحديث.
- الصور والخطوط الأصلية ورخصة الخط لا تزال محفوظة في جذر المستودع.

## بناء الملفات محليًا

أداة البناء تعيد ضغط الصورة والشعار، وتحوّل Tajawal إلى WOFF2، ثم تنشئ الصفحات الأربع وملف `vercel.json` و`robots.txt`. تُحفظ ملفات HTML الناتجة في المستودع، لذا لا يحتاج نشر Vercel إلى تشغيل الأداة.

```bash
python3 -m pip install Pillow fonttools brotli
python3 tools/build_landing_pages.py
```

عدّل النصوص والرسائل والأسئلة في كائن `PAGES` داخل `tools/build_landing_pages.py`، ثم شغّل الأداة وافحص الفروق قبل الرفع. يبقى `index.html` هو fallback في GitHub Pages وأي استضافة ملفات ثابتة لا تنفذ قواعد Vercel.

## قياس النقرات

تحافظ الصفحة على اسم حدث GTM الحالي `contact_click` وتضيف الحقول المطلوبة:

| الحقل | القيمة |
|---|---|
| `service` و`landing_service` | `general` أو `criminal` أو `family` أو `documentation` |
| `position` و`contact_placement` | `hero` أو `chip` أو `popup` أو `sticky` |
| `contact_method` و`contact_channel` | `phone` أو `whatsapp` |
| `legal_service` | مجموعة الخدمة التي تخص الصفحة |

تدفع الصفحة حدث `welcome_popup_view` عند ظهور النافذة، ولا تعتبره تحويل اتصال. `contact_click` يقيس نية النقر فقط؛ لا يثبت إجراء مكالمة أو إرسال رسالة. أُبقي معرف الحاوية الموجود `GTM-KKHH6SBP` من دون تغيير إعدادات حساب GTM أو Google Ads. قبل الاعتماد على التحويلات، اختبر المشغّل والوسم في GTM/Tag Assistant وتأكد من إعدادات الموافقة وسياسة الخصوصية للحاوية.

## النشر والتحقق

المستودع: `el7usseinelabd-ux/ads.landing-law`، والفرع المستهدف `main`. عند دفع الملفات إلى الفرع، ينشر Vercel النسخة المرتبطة بالمستودع تلقائيًا. بعد اكتمال النشر اختبر الروابط الأربع ومعاملات الحملة، ثم اختبر الاتصال وواتساب والنافذة على الهاتف.

لم يتم تعديل حساب Google Ads أو إنشاء حملات. أزرار الاتصال تفتح تطبيق الهاتف، وأزرار واتساب تفتح مسودة رسالة يمكن للزائر مراجعتها قبل الإرسال.
